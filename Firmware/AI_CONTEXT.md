# قوانین

قبل از هر تغییر این فایل را بخوان.

## کامنت فایل

بالای هر فایل `.c` / `.h`:
- لحن مهندسی، نه آموزشی
- انگلیسی و فارسی

## کامنت تابع

بالای هر تابع:
- کار تابع چیست (انگلیسی و فارسی)
- هر پارامتر یعنی چی، واحدش چیست، محدوده‌اش چیست (مثلاً mV، ms، درصد)
- مقدار برگشتی چیست
- مثال: `@param u32_batteryMv [EN] Battery voltage in mV, 21V=0% 28V=100% / ولتاژ باتری`
- انگلیسی و فارسی اجباری

## هماهنگی

قبل از **هر** تغییر (کد، README، AI، پوشه):
1. بگو کدام فایل‌ها عوض می‌شوند
2. بگو چرا
3. صبر کن تا کاربر تأیید کند
4. بعد انجام بده

بدون تأیید، فایل را عوض نکن.

## MISRA C

همهٔ کد روی MISRA C نوشته شود.

## سادگی و خوانایی توابع

توابع را ساده و خوانا بنویس تا بشه بعدا اصلاحشون کرد — صرفاً خطی ننویس چون از خوانایی می‌اندازد.
- هر تابع یک کار کند (Single Responsibility)
- از ifهای تودرتوی عمیق پرهیز کن، ولی گام‌ها را با نام متغیر واضح و کامنت جدا کن تا خوانا بماند، نه فقط پشت‌سرهم on/delay/off
- پارامترهای قابل تنظیم (مین/ماکس، تایم) را در فایل واحد خودش بگذار (مثل `ui_config.h`) تا تکراری در ۲-۳ فایل نباشد
- تابع بازر جدا باشد و از هر سناریو قابل صدا زدن باشد
- نام متغیر: اول تایپ بعد نام؛ گلوبال تایپ با حروف بزرگ (U32_G_)، داخلی کوچک (u32_)
- بالای هر تابع حتماً توضیح بده چیکار می‌کنه و هر پارامتر یعنی چی (واحد، محدوده)

## برگه هر ماژول

ریشهٔ `Firmware` برگهٔ README جدا ندارد. فقط همین فایل AI.

هر ماژول یک `README.md` داخل **همان پوشه** دارد. راهنمای ماژول دیگر ساخته نشود.

هر بار همان ماژول عوض شد، همان جلسه یک خط در بخش **تاریخچه** همان README اضافه کن.

قالب اجباری `README.md` ماژول:

1. **وضعیت** — فعال یا اسکلت؛ مقدار `MODULE_*` در `modules_enable.h`
2. **تاریخچه** — تاریخ + چه عوض شد (از جدید به قدیم)
3. **فایل‌ها** — `.c` / `.h` همین پوشه و تسک مربوط در `Rtos`
4. **توابع** — نام دقیق + کار (عمومی، `static` داخلی، تسک)
5. **پایه‌ها** — شماره (مثل PB0) + لیبل Cube/شماتیک + نقش + HIGH یعنی چه
6. **پیش‌فرض امن** — بعد از `Init` خروجی‌ها چه وضعی دارند
7. **درخت اتصال** — این ماژول به کدام فایل‌ها وصل است (صدا می‌زند / صدا زده می‌شود)

اگر ماژول پایهٔ GPIO ندارد، در بخش پایه‌ها صریح بنویس: پایه ندارد.

قطبیت تا روی برد اندازه نشده «شماتیک» است، نه اندازه‌گیری‌شده.

ADC / PWM / UART / رله را در برگهٔ ماژول خاموش، Enable نکن مگر کاربر همان مرحله را خواسته باشد.
