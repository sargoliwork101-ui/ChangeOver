# تستر ماژول McuPowerPath

تست هاست مسیر تغذیهٔ MCU. کد **محصول** (`../mcu_power_path.c`) بدون تغییر
کامپایل می‌شود و ساعت، GPIO و snapshot بدلی‌اند.

## اجرا
```bash
./Firmware/Modules/McuPowerPath/Tester/run_host_test_mcu_power_path.sh
```

## پوشش (۴۹ بررسی)
۱. `Init` تغذیه را روی باتری (سمت امن) پارک می‌کند.
۲. برداشتن باتری فقط پس از **۵ ثانیهٔ کامل** ورودی ≥ ۲۲۰۰۰mV.
۳. افت زیر ۲۱۵۰۰mV فوراً باتری را برمی‌گرداند.
۴. نوار هیسترزیس (۲۱۵۰۰ تا ۲۱۹۹۹) هیچ تصمیمی نمی‌سازد و تایمر هم نمی‌دود.
۵. افتِ وسط پنجره، ساعت ۵ ثانیه را از نو شروع می‌کند.
۶. نبود اندازه‌گیری معتبر تصمیم را فریز می‌کند.
۷. پایهٔ حضور ورودی در لحظهٔ برداشتن حق وتو دارد.
۸. وقفهٔ «ورودی رفت» فوراً باتری را برمی‌گرداند، و همان وقفه وقتی ورودی هست
   کلید را دست نمی‌زند.
۹. سرریز شمارندهٔ تیک (۴۹٫۷ روز) پنجرهٔ ۵ ثانیه را خراب نمی‌کند.
