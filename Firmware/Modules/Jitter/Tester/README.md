# تستر ماژول Jitter

تست هاست آشکارساز جیتر. کد **محصول** (`../jitter.c`) بدون تغییر کامپایل
می‌شود و لایهٔ `EXTI` برد بدلی است تا تست «لبهٔ سخت‌افزاری» را دستی تزریق کند.

## اجرا
```bash
./Firmware/Modules/Jitter/Tester/run_host_test_jitter.sh
```

## پوشش (۲۴ بررسی)
۱. `Init` لایهٔ برد را مسلح می‌کند و بدون تریپ شروع می‌شود.
۲. یک لبه روی کانال ۱ فقط کانال ۱ را تریپ می‌کند.
۳. تریپ **قفل** می‌ماند؛ بخشیدنش کار شارژر است نه آشکارساز.
۴. پاک‌کردن یک کانال هرگز کانال دیگر را پاک نمی‌کند.
۵. رویداد BSP یک‌بارمصرف است: تریپِ پاک‌شده خودبه‌خود برنمی‌گردد.
۶. شمارهٔ کانال خارج از ۱..۲ رد می‌شود (نه نگاشت می‌شود نه خطا می‌دهد).
