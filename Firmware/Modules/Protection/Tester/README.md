# تستر ماژول Protection

تست هاست نگهبان اعتبار اندازه‌گیری. کد **محصول** (`../protection.c`) بدون
تغییر کامپایل می‌شود و ماژول فالت بدلی است تا دیده شود دقیقاً کدام بیت
دست‌کاری می‌شود.

## اجرا
```bash
./Firmware/Modules/Protection/Tester/run_host_test_protection.sh
```

## پوشش (۶۱ بررسی)
۱. `Init` هیچ بیتی را دست نمی‌زند.
۲. `snapshot` خالی یا نامعتبر دقیقاً بیت `FAULT_ADC` را بالا می‌برد، نه چیز دیگر.
۳. **قانون اصلی:** این بیت «زنده» است نه قفل‌شونده — اولین snapshot سالم آن را
   پاک می‌کند. اگر این بررسی بیفتد، دستگاه تا پایان همان روشن‌بودن در حالت امن
   قفل می‌ماند.
۴. بیت‌های دیگر (مثل قطع باتری) در هر دو جهت دست‌نخورده می‌مانند.
۵. نوسان سریع اعتبار در ۵۰ پاس پشت‌سرهم درست دنبال می‌شود.
