# تستر ماژول Fault

تست هاست ماژول خطا. کد **محصول** (`../fault.c`) بدون تغییر کامپایل می‌شود و
بدل‌ها فقط نمادهای بیرونی را می‌دهند:

| بدل | کار |
|---|---|
| ساعت کرنل | شمارندهٔ تیک دستی (۱ تیک = ۱ میلی‌ثانیه) |
| `osKernelLock` / `osKernelRestoreLock` | روی هاست تک‌نخ است، فقط یک ژتون برمی‌گرداند |
| شارژر | «کدام کانال پمپ می‌کند»، «مود تست دستی روشن است؟» و اعداد پروفایل/آلارم |

## اجرا

```bash
./Firmware/Modules/Fault/Tester/run_host_test_fault.sh
```

این اجراکننده هم داخل `tools/check_firmware_syntax.sh` صدا زده می‌شود.

## چه چیزهایی پوشش دارد (۴۴ بررسی)

۱. API ماسک: `Set` / `Clear` / `Get` / `Any`، و بی‌اثر بودن ست صفر یا پاک‌کردن
   بیت خاموش.
۲. نبود snapshot یا snapshot نامعتبر: هیچ بیتی قفل نمی‌شود و دبانس‌ها صفر
   می‌مانند.
۳. آشکارساز ۱ (نیمِ پمپ‌شده بالای حد قطع): بدون پمپ هیچ قفلی نیست (اصلاح
   v1.21 چرخهٔ سه‌بوق کاذب)، با پمپِ **کانال خودِ همان نیم** پس از دبانس
   ۱۵۰ms قفل می‌شود، و کانال اشتباه نیم دیگر را مسلح نمی‌کند.
۴. آشکارساز ۲ (نیم زیر ۶ ولت با ورودی سالم) با دبانس ۱ ثانیه؛ ورودی خارج از
   بازه — چه پایین‌تر چه بالاتر — اجازهٔ قضاوت نمی‌دهد.
۵. بازیابی روی ۷ ولت با هیسترزیس ۱ ولت: بین ۶ و ۷ ولت بیت قفل‌شده می‌ماند.
۶. مود تست دستی هم قفل‌شدن و هم پاک‌شدن را فریز می‌کند.
۷. پارامترهای آلارم: گیرهٔ کف و سقف، حفظ ۵۰۰mV هیسترزیس بین absent/back، و رد
   شناسهٔ بیگانه.
۸. سرریز شمارندهٔ تیک وسط دبانس.
