# پنل ساده کاربر - ChangeOver

پنل کاملا جدا از پنل فنی `esp_link_panel` برای کاربر ساده.

## هدف
کاربر ساده فقط می‌خواهد بداند:
- برق شهر وصل است یا قطع
- باتری چند درصد دارد - مثل موبایل
- هر نیم‌باتری چقدر شارژ دارد
- سیستم سالم است یا خطا دارد

بدون عدد فنی، بدون جریان، بدون PID، بدون تنظیمات.

## چی نشان می‌دهد
- **وضعیت کلی** با جمله ساده فارسی و آیکون:
  - ✅ باتری پر - برق شهر وصل
  - ⚡ در حال شارژ
  - 🔋 روی باتری - برق شهر قطع
  - ⛔ ارتباط قطع / خطا
- **باتری اصلی** با شکل باتری موبایل و درصد بزرگ 0 تا 100
  - ولتاژ پک و ورودی
- **نیم‌باتری‌ها** بالا و پایین هر کدام با درصد و ولتاژ
  - اگر اختلاف زیاد باشد هشدار عدم تعادل
- **چراغ‌های روی برد** سبز/زرد/قرمز شبیه‌سازی ساده
- **پیغام سیستم** فارسی ساده:
  - باتری قطع شده
  - خطای فنی
  - اختلاف باتری‌ها
  - باتری کم

## فنی
- همان ESP8266، همان سیم‌بندی: PA9 -> RX، PA10 -> TX، GND مشترک
- باود 921600 8N1
- فقط تله‌متری TLM_LIVE را می‌خواند (AA 55 + نسخه 2 + CRC16)
- چیزی به برد نمی‌فرستد - فقط خواندنی، امن
- وای‌فای AP: `changeover_userpannel` رمز `123456789`
- آدرس: `http://192.168.4.1`
- صفحه تک‌فایل سبک ~25KB، بدون نیاز به LittleFS
- مسیرها: `/` صفحه، `/t` تله‌متری JSON

## ساختار پوشه
- `esp_simple_panel.ino` - راه‌اندازی
- `simple_config.h` - ثابت‌ها
- `simple_state.h` - داده زنده
- `simple_link.h` - پارسر فریم
- `simple_http.h` - وب‌سرور
- `simple_panel.h` - HTML
- `README.md` - همین فایل

## فلش کردن
1. در Arduino IDE برد `NodeMCU 1.0 (ESP-12E)` یا `LOLIN WEMOS D1 mini` انتخاب شود
2. فایل `esp_simple_panel.ino` باز شود
3. آپلود
4. به وای‌فای `changeover_userpannel` وصل شوید
5. مرورگر `192.168.4.1`

## قوانین
- کامنت‌ها فقط فارسی - استثنای پنل ESP
- هیچ تغییری در `Firmware/` و `esp_link_panel` نمی‌دهد
- نام‌گذاری `func__` و `TYPE__G__` مثل پروژه اصلی
- تک واحد ترجمه

## تفاوت با پنل فنی
| پنل فنی | پنل ساده |
|---|---|
| 143 پارامتر قابل تنظیم | صفر پارامتر |
| نمودار شارژ، PID، کالیبراسیون | فقط درصد باتری |
| بنچ و لاگ | ندارد |
| ~416KB | ~25KB |
| برای مهندس | برای کاربر نهایی |
