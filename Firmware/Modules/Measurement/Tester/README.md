# تستر ماژول Measurement

تست هاست زنجیرهٔ اندازه‌گیری. کد **محصول** (`../measurement.c`) بدون تغییر
کامپایل می‌شود و فریم‌های ADC مصنوعی از طریق BSP بدلی به آن داده می‌شود.

ریاضیات تبدیل در بدل عمداً **خطی** است (هر شمارش = ۱۰ میلی‌ولت، هر شمارش =
۱ میلی‌آمپر) تا هر عدد انتظاری با دست قابل‌محاسبه باشد و تست «رفتار ماژول» را
بسنجد نه کالیبراسیون برد را.

## اجرا
```bash
./Firmware/Modules/Measurement/Tester/run_host_test_measurement.sh
```

## پوشش (۲۸۶ بررسی)
۱. تا کامل‌شدن فریم‌های گرم‌شدن هیچ‌چیز معتبر نیست.
۲. اعداد منتشرشده دقیقاً با ریاضیات بدل می‌خوانند.
۳. نیم پایین/بالا مشتق‌اند (۱۲ ولت و باقی‌ماندهٔ پک ۲۴ ولت).
۴. پرچم حضور ورودی از پایهٔ برد می‌آید.
۵. فریمی که برد نمی‌دهد، snapshot را نامعتبر می‌کند و با بازگشت فریم‌ها خودش
   درمان می‌شود — دادهٔ کهنه منجمد نمی‌ماند.
۶. `GetSnapshot(NULL)` رد می‌شود.
۷. یک نمونهٔ پرت (نویز کلیدزنی) از فیلتر میانه رد نمی‌شود.
۸. پارامترهای فیلتر گیره و بازخوانی می‌شوند.
۹. آفست ولتاژ: گیرهٔ متقارن، رد کانال ناشناخته، و اثر دقیق ۵۰۰ میلی‌ولت روی
   مقدار منتشرشده.
۱۰. `Init` واقعاً ماژول را از نو شروع می‌کند.
