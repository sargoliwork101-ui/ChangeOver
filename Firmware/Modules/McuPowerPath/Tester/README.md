# تستر ماژول McuPowerPath

تست هاست مسیر تغذیهٔ MCU. کد **محصول** (`../mcu_power_path.c`) بدون تغییر
کامپایل می‌شود و ساعت، GPIO و snapshot بدلی‌اند.

## اجرا
```bash
./Firmware/Modules/McuPowerPath/Tester/run_host_test_mcu_power_path.sh
```

## پوشش (۶۷ بررسی)
۱. `Init` تغذیه را روی باتری (سمت امن) پارک می‌کند.
۲. برداشتن باتری فقط پس از **۵ ثانیهٔ کامل** مجوز مشترک اشمیت Fault
   (پنجرهٔ `q33/q34` + حاشیه‌های `q169/q170`؛ پیش‌فرض برگشت `21500..27500mV`).
۳. افت زیر لبهٔ خام پایین (پیش‌فرض `<21000mV`) فوراً باتری را برمی‌گرداند.
۴. داخل پنجرهٔ خام ولی زیر حاشیهٔ برگشت، مجوز هنوز false است و تایمر نمی‌دود.
۵. افتِ وسط پنجره، ساعت ۵ ثانیه را از نو شروع می‌کند.
۶. نبود اندازه‌گیری معتبر تصمیم را فریز می‌کند.
۷. پایهٔ حضور ورودی در لحظهٔ برداشتن حق وتو دارد.
۸. وقفهٔ «ورودی رفت» فوراً باتری را برمی‌گرداند، و همان وقفه وقتی ورودی هست
   کلید را دست نمی‌زند.
۹. سرریز شمارندهٔ تیک (۴۹٫۷ روز) پنجرهٔ ۵ ثانیه را خراب نمی‌کند.
۱۰. لبهٔ خام بالا هم باتری را برمی‌گرداند (پیش‌فرض `>28000mV`) و داخل پنجره
    ولی بالای حاشیهٔ برگشت (`27501..28000`) مجوز false می‌ماند.
۱۱. تغییر زندهٔ پنجرهٔ پنل هر دو لبه را جابه‌جا می‌کند.
۱۲. پنجرهٔ باریک پنل حاشیه‌های داخلی را گیره می‌زند و باندها را وارونه نمی‌کند.
