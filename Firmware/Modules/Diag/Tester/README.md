# تست هاست ماژول Diag

خودِ `../diag.c` کامپایل و اجرا می‌شود؛ هیچ نسخهٔ کپی‌شده‌ای وجود ندارد.

اجرا:

```bash
bash Firmware/Modules/Diag/Tester/run_host_test_diag.sh
```

## دنیای بدلی

| بدل | چرا |
|---|---|
| `osKernelGetTickCount` / `osKernelGetTickFreq` | ساعت کرنل ۱ کیلوهرتز که تست ثانیه‌به‌ثانیه جلو می‌برد |
| `osKernelLock` / `osKernelRestoreLock` | روی هاست یک نخ هست، یک ژتون کافی است |
| `func__Charger_IsChannelActive` و `IsSuspended` / `SetSuspended` | وضعیت شارژ و پنجرهٔ تعلیق نوشتن فلش |
| `func__BspPwm_StopAll` | توقف گیت‌ها در پنجرهٔ کور |
| `func__BspFlash_ErasePage` / `ProgramHalfWords` | دو صفحهٔ واقعی فلش که با `mmap` روی آدرس سخت‌افزاری `0x0800F800` و `0x0800FC00` نگاشت شده‌اند، چون ماژول رکوردش را مستقیم از همان آدرس می‌خواند |
| `UINT32_T__G__ChargerDiag` | جدول تصویر تصمیم شارژر برای ثبت حالت دو کانال در خطا (این تست مسیر خطا را اجرا نمی‌کند) |

## چه چیزی ثابت می‌شود (۳۱ بررسی)

1. **آپتایم از تیک کرنل**: بعد از ۳۰ ثانیهٔ واقعی و اولین تیک، آپتایم ۳۰ است نه ۱؛ تیک دیررس زمانی را گم نمی‌کند؛ و سرریز ۳۲بیتی تیک آپتایم را عقب نمی‌برد.
2. **ثانیه‌های شارژ از اختلاف آپتایم**: هشت ثانیه شارژ هشت ثانیه می‌شود؛ دو کانال در یک ثانیه به «مجموع» فقط یکی اضافه می‌کنند؛ دو بار صدا زدن در یک ثانیه چیزی اضافه نمی‌کند؛ کانال بی‌کار از زمان بی‌کاری چیزی اضافه نمی‌کند؛ و صدازنندهٔ کند باز هم دقیق می‌شمارد.
3. **ذخیره حین شارژ**: در ۵۹۸ ثانیهٔ اول شارژ هیچ نوشتنی روی فلش نمی‌رود، در دقیقهٔ دهم یک نوشتن انجام می‌شود «بی‌آنکه شارژ تمام شود»، و ده دقیقهٔ بعد نوشتن بعدی.
4. **پایان شارژ**: شارژ کوتاه با همان دیبانس ۶۰ ثانیه‌ای ذخیره می‌شود و ثانیهٔ آرام بعد از آن هیچ نوشتنی ندارد.

## سنجش A/B پیش از اصلاح

همین دو رفتار روی `diag.c` قبل از اصلاح اندازه‌گیری شد:

| سنجش | قبل | بعد |
|---|---|---|
| آپتایم بعد از ۳۰ ثانیهٔ واقعی | ۱ ثانیه | ۳۰ ثانیه |
| آپتایم پس از ۲۱۶۰ ثانیه با پاس ۱۲ میلی‌ثانیه‌ای | ۱۸۰۰ ثانیه (۱۶٪ کند) | ۲۱۹۰ ثانیه (دقیق) |
| ثانیهٔ شارژ در همان اجرا | ۱۸۰۰ | ۲۱۵۹ |
| نوشتن فلش در ۱۸۰۰ ثانیه شارژ | ۰ | ۳ |

تست هاست جای تست برد را نمی‌گیرد؛ این چهار عدد باید یک بار روی برد هم دیده شوند و در `Diag_Validation.xlsx` ثبت شوند.
