# Commissioning Checklist

## قبل از تغذیه

- [ ] اتصال کوتاه بین 24V و GND بررسی شده است.
- [ ] منبع آزمایشگاهی جریان‌محدود تنظیم شده است.
- [ ] ریل‌های 3.3V، 5V و 12V بدون فعال‌کردن توان تأیید شده‌اند.
- [ ] جهت MOSFET، دیود و TVS بررسی شده است.
- [ ] مقادیر مقاومت‌های تقسیم ADC با BOM تطبیق داده شده‌اند.

## Bring-up نرم‌افزار

- [ ] فقط GPIO و LED تست شده است.
- [ ] UART با PWM خاموش تست شده است.
- [ ] ADC با مولتی‌متر مقایسه شده است.
- [ ] ضرایب ولتاژ و جریان کالیبره شده‌اند.
- [ ] PWM بدون اتصال به مرحله‌ی قدرت روی اسیلوسکوپ تست شده است.
- [ ] Jitter1 و Jitter2 با سیگنال کنترل‌شده تست شده‌اند.
- [ ] active level رله و Battery Switch تأیید شده است.

## تست توان

- [ ] Duty اولیه صفر است.
- [ ] Over Current باعث خاموشی می‌شود.
- [ ] Low Battery باعث حفاظت می‌شود.
- [ ] ورودی 24V قطع و وصل شده و State درست تغییر می‌کند.
- [ ] Break-Before-Make با اسیلوسکوپ بررسی شده است.
- [ ] تست با بار کم و منبع جریان‌محدود انجام شده است.
- [ ] Watchdog و Fault Recovery تست شده‌اند.
