# آزمایشگاه پنل کاربری ESP

این پوشه یک **ابزار توسعه** است، نه بخشی از فرم‌ور. هیچ فایلی از خود پنل تغییر نمی‌کند؛
سرور، صفحه را عیناً از رشتهٔ داخل `simple_panel.h` می‌خواند و همان مسیرهایی را جواب
می‌دهد که پنل صدا می‌زند (`simple_http.h`).

## اجرا

```
python3 ESP_USER/Simulator/lab/server.py --port 8090
```

سپس در مرورگر:

- `/` — خود پنل با یک برد شبیه‌سازی‌شده (ولتاژ، مرحلهٔ شارژ، خطا، قطعی برق، تاریخچه)
- `/lab` — فهرست ایرادهای بررسی‌شده، هر کدام با خلاصه، یک مثال واقعی و یک پیشنهاد
- `/lab` → دکمهٔ «اجرا» — همان کد C پنل با شیم‌های پروژه کامپایل و اجرا می‌شود و
  خروجی خام هارنس نمایش داده می‌شود (این تنها بخشی است که واقعاً روی کد پنل اجرا می‌شود)

## چه چیزی واقعی است

- HTML/JS/CSS از `simple_panel.h` استخراج می‌شود (بدون کپی دستی).
- نام مسیرها، پارامترها و کلیدهای JSON از `simple_http.h`.
- خروجی هارنس از `Tester/host_test_latch.cpp` + `probe_panel_defects.cpp` با
  `-fsanitize=address,undefined`.

## چه چیزی شبیه‌سازی است

- برد و فلش: در حافظه؛ هیچ سخت‌افزاری لازم نیست.
- قفل «یک نشست در هر لحظه» عمداً **خاموش** است تا ورود اذیت نشوی؛ از دکمهٔ خودش در
  `/lab` روشنش کن تا ایراد ۸ را با چشم ببینی.

## نوشتن گزارش برای دیگران

```
python3 ESP_USER/Simulator/lab/server.py --export   # می‌سازد: FINDINGS.md
```
